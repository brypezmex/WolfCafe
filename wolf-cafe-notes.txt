## Implement Items
Start implementing Items without Categories

- entity.Item
	- Create fields
		- id: @Id, @GeneratedValue(strategy = GenerationType.IDENTITY)
		- name: not null, unique
		- description
		- price: not null
	- Annotations
		@Getter
		@Setter
		@NoArgsConstructor
		@AllArgsConstructor
		@Entity
		@Table(name = "items")
- repository.ItemRepository (Interface)
	extends JpaRepository<T, ID> where T is the entity and ID is the type of the primary key
- dto.ItemDto
	- Create fields for id, name, description, price (no need for category here)
	- Annotations
		@Getter
		@Setter
		@NoArgsConstructor
		@AllArgsConstructor
- service.ItemService (Interface)
	- Add methods for REST API functionality
	    ItemDto addItem(ItemDto itemDto);

		ItemDto getItem(Long id);

		List<ItemDto> getAllItems();

		ItemDto updateItem(Long id, ItemDto itemDto);

		void deleteItem(Long id);
- service.impl.ItemServiceImpl
	- Implements ItemService
	- Annotations
		- @Service
		- @AllArgsConstructor
	- Inject dependencies
